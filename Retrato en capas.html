Noa Juarez, en capas

Retrato ilustrado de Noa a los 9 años: pelo moreno rizado y ojos marrones. Mueve el ratón (o el dedo) por la página; cada parte del dibujo se desplaza según su profundidad.

Pasa el puntero por la página para que gire la cabeza.

Puntero normalizado

--x (izq. −1 · dcha. 1)0.00
--y (arriba −1 · abajo 1)0.00

Ajustes

Capas (de atrás a delante)

    Pasa el puntero por una capa de la lista para aislarla. Los números son los píxeles máximos que se desplaza en X y en Y.

    Cómo funciona

    1. El retrato de Noa se divide en 11 capas SVG del mismo tamaño (viewBox idéntico) apiladas con position: absolute.
    2. Cada capa es un div, no un grupo dentro de un único SVG: así el navegador las mueve con transform, que va por GPU y no obliga a redibujar el SVG.
    3. JavaScript convierte la posición del puntero en dos números entre −1 y 1 respecto al centro del retrato y los guarda como variables CSS --x y --y.
    4. Cada capa multiplica esos valores por su propia profundidad (--dx, --dy). Los rizos delanteros y la nariz se mueven más que el fondo. Esa diferencia crea el efecto 3D.
    5. Un bucle con requestAnimationFrame acerca poco a poco el valor actual al del puntero (interpolación lineal), lo que da la sensación de inercia.
    /* CSS: una regla sirve para todas las capas */
.layer {
  transform: translate(
    calc(var(--x) * var(--dx) * 1px),
    calc(var(--y) * var(--dy) * 1px));
}

// JS: puntero → objetivo entre -1 y 1
addEventListener('pointermove', e => {
  const r = stage.getBoundingClientRect();
  tx = clamp((e.clientX - (r.left + r.width / 2)) / (innerWidth / 2));
  ty = clamp((e.clientY - (r.top + r.height / 2)) / (innerHeight / 2));
});

// Bucle: acercarse un 12 % cada fotograma
(function loop() {
  x += (tx - x) * 0.12;
  y += (ty - y) * 0.12;
  stage.style.setProperty('--x', x);
  stage.style.setProperty('--y', y);
  requestAnimationFrame(loop);
})();

    Si el sistema pide reducir el movimiento, la demo baja la amplitud y quita el parpadeo.
